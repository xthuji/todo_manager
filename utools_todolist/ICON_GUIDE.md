# 图标文件创建指南

## 需要创建的图标文件

### 1. 插件主图标
- **文件名**: `logo.png`
- **尺寸**: 128x128px (推荐)
- **位置**: 项目根目录
- **建议**: 使用favicon.png作为基础，调整尺寸

### 2. 功能图标
- **todo-icon.png**: 任务管理图标 (建议使用任务列表图标)
- **festival-icon.png**: 节日管理图标 (建议使用节日/庆祝图标)  
- **calendar-icon.png**: 日历视图图标 (建议使用日历图标)
- **weather-icon.png**: 天气查询图标 (建议使用云朵/天气图标)

**尺寸**: 64x64px 或 128x128px
**位置**: assets/img/ 目录

## 临时解决方案
可以使用现有的favicon.png复制并重命名为logo.png
可以使用现有的天气图标复制并重命名为对应的功能图标
