## 编写规范

新增 ADR 时遵循：

1. 文件名：`NNNN-简短标题.md`，编号从 0001 开始递增，不重复。
2. 状态：提议 / 已接受 / 已废弃 / 已替代。
3. 日期：决策日期（YYYY-MM-DD）。
4. 内容结构：背景 → 决策 → 理由 → 备选方案 → 后果 → 相关 ADR。
5. **不删除已接受的 ADR**：决策变更时新建 ADR 并将旧的标记为"已替代"，引用新的编号。
