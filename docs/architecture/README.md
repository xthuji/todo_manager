## 快速路径

### 我是新人，想快速上手
1. 读 [01-overview.md](01-overview.md) 了解项目定位与「四页面拼一个应用」的结构
2. 读 [02-pages/00-app-shell.md](02-pages/00-app-shell.md) 理解外壳如何装载页面
3. 挑一个你最关心的业务页深入（推荐从 [todo.md](02-pages/todo.md) 或 [weather.md](02-pages/weather.md) 开始）
4. 按 [06-onboarding.md](06-onboarding.md) 在本地把服务跑起来
5. 动手改功能前对照 [07-dev-guide.md](07-dev-guide.md) 的规范

### 我想理解某块业务
- 能归入页面的：去 [02-pages/](02-pages/) 找对应页面文档，里面有完整前后端调用链
- 不属于任何页面的（定时通知、节假日/节日共享域）：去 [03-business/](03-business/)

### 我想知道某个共性技术（缓存/并发/配置）怎么实现
- 看 [04-infrastructure.md](04-infrastructure.md)

### 我想知道某个技术选型的理由
- 看 [01-overview.md](01-overview.md) §6.1 关键选型理由（webview_go / 多源天气 / universal 构建）
